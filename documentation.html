💊 Medication Reminder Chatbot

Label-Aware Medical Assistant using RAG Architecture

Overview Architecture Installation Components Usage API Reference

📋 Project Overview

The Medication Reminder Chatbot is an intelligent healthcare assistant that leverages Retrieval Augmented Generation (RAG) to provide accurate, label-based information about medications. Built with a focus on safety and accuracy, it retrieves information directly from FDA drug labels stored in a vector database.

Key Features

🔍 Intelligent Q&A

Ask natural language questions about medications and receive accurate answers sourced directly from official drug labels.

⏰ Smart Reminders

Automatically generate medication reminder schedules based on dosage instructions from the drug label.

💬 Multi-Chat Interface

Manage multiple conversations simultaneously with separate context for different medications.

🛡️ Safety Guardrails

Built-in validation ensures queries are safe and responses stay within label information boundaries.

🤖 Autonomous Ingestion

Automatically processes and indexes drug label data on first run without manual intervention.

📊 Vector Search

ChromaDB-powered semantic search finds relevant information quickly across large datasets.

Technology Stack

Streamlit LangChain ChromaDB Ollama (Llama 3) Python 3.8+ RAG Architecture

🏗️ System Architecture

Project Structure

medication_bot/
│
├── app.py # Streamlit UI and interaction logic
├── agents.py # Ingestion, QA, Reminder agents
├── vectorstore.py # ChromaDB setup and helpers
├── guardrails.py # Input validation and safety checks
├── evals.py # Basic evaluation utilities
├── ingest.py # Manual ingestion script
├── sample.txt # Drug label data (openFDA-style JSON)
├── chroma_poc/ # Persisted vector database
├── requirements.txt # Dependencies
└── README.md # Project documentation

RAG Pipeline Flow

1. Data Ingestion: FDA drug labels (JSON) → Document chunking → Embedding generation → ChromaDB storage

2. Query Processing: User question → Embedding → Semantic search → Relevant chunks retrieval

3. Response Generation: Retrieved context + User query → LLM (Llama 3) → Grounded response

Agent Architecture

Agent Responsibility Output
Ingestion Agent Processes FDA JSON records into structured documents Document objects with metadata
Q&A Agent Answers questions using retrieved label context Natural language responses
Reminder Agent Generates medication schedules from dosage info Structured JSON reminders

⚙️ Installation & Setup

Prerequisites

  • Python 3.8 or higher
  • Ollama installed and running locally
  • Llama 3 8B model pulled in Ollama
  • Nomic Embed Text model for embeddings

Step 1: Install Ollama

# Visit https://ollama.ai and install for your OS # Pull required models: ollama pull llama3:8b ollama pull nomic-embed-text

Step 2: Clone Repository

git clone <repository-url> cd medication_bot

Step 3: Install Dependencies

pip install -r requirements.txt
⚠️ Note: The requirements.txt includes: streamlit, langchain, langchain-community, chromadb, and ollama packages.

Step 4: Prepare Data

Ensure sample.txt contains FDA drug label data in JSON format. The system expects an array of records with openFDA-compatible structure.

Step 5: Run the Application

streamlit run app.py
ℹ️ Automatic Ingestion: On first run, the system automatically detects an empty database and ingests data from sample.txt. No manual ingestion needed!

Streamlit-based user interface providing chat functionality and medication management.

Key Features:

Basic quality checks for retrieval and generation outputs.

Evaluation Functions:

6. ingest.py - Manual Ingestion Script

Standalone script for manually processing and indexing drug label data.

Note: This script is optional as autonomous_ingestion() in agents.py handles ingestion automatically on first app run.

Process Flow:

  1. Load JSON records from sample.txt
  2. Process each record through ingestion_agent()
  3. Generate embeddings using nomic-embed-text
  4. Store in ChromaDB with persistence

🚀 Usage Guide

Starting the Application

# Navigate to project directory cd medication_bot # Launch Streamlit app streamlit run app.py # Access at http://localhost:8501

Workflow

Step 1: Select Medication

Choose a drug from the dropdown menu. Available medications are loaded dynamically from the vector database.

Step 2: Ask Questions

Type natural language questions about the medication:

  • "What are the side effects?"
  • "Can I take this while pregnant?"
  • "What are the drug interactions?"
  • "What is the recommended dosage?"

Step 3: Generate Reminders

Click the "Generate Reminder" button or type "reminder" to create a medication schedule based on dosage instructions.

Step 4: Manage Chats

  • Use sidebar to create new chats or switch between existing ones
  • Each chat maintains independent context and product selection
  • Use /change to switch medications within a chat
  • Use /quit to reset the current chat

Example Interactions

// Example 1: Basic Question User: What is this medication used for? Bot: [Retrieves and summarizes indications_and_usage section] // Example 2: Safety Query User: Are there any warnings I should know about? Bot: [Provides warnings from the drug label] // Example 3: Reminder Generation User: reminder Bot: [Outputs structured JSON schedule]

Best Practices

  • ✅ Ask specific, focused questions for best results
  • ✅ Review the complete drug label for comprehensive information
  • ✅ Use reminders as supplementary tools, not replacements for medical advice
  • ❌ Do not use for emergency medical situations
  • ❌ Do not consider responses as professional medical advice
⚠️ Medical Disclaimer: This chatbot provides information from drug labels only. It is NOT a substitute for professional medical advice, diagnosis, or treatment. Always consult with a qualified healthcare provider for medical questions.

📚 API Reference

Core Agent Functions

ingestion_agent(record)

Parameters:

  • record (dict): FDA JSON record with drug label data

Returns: List of Document objects with structured sections

Description: Processes a single FDA drug label record into multiple documents, one per section (indications, warnings, dosage, etc.)

ask_drug(product, question)

Parameters:

  • product (str): Name of the medication
  • question (str): User's question

Returns: String response from LLM

Description: Retrieves relevant context and generates an answer using the Q&A agent

reminder_agent(product)

Parameters:

  • product (str): Name of the medication

Returns: Dict with parsed JSON or raw text fallback

Description: Generates a medication reminder schedule based on dosage information

autonomous_ingestion()

Parameters: None

Returns: ChromaDB vectorstore instance

Description: Automatically checks if database is empty and performs ingestion if needed

Vectorstore Functions

get_vectorstore()

Returns: Chroma vectorstore instance

Description: Initializes ChromaDB with nomic-embed-text embeddings

get_available_products(vectorstore)

Parameters:

  • vectorstore: ChromaDB instance

Returns: Sorted list of unique product names

Description: Extracts all unique medication names from database metadata

is_db_empty(vectorstore)

Parameters:

  • vectorstore: ChromaDB instance

Returns: Boolean indicating if database is empty

Description: Checks if vectorstore needs initialization
